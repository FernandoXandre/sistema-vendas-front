- Soap - (
    é um protocolo (conjunto de regras) para comunicação entre sistemas que exigem a garantia de compatibilidade e segurança
    utiliza XML para comunicação e necessita de um formato padrao (Envelope, Header, Body)
    comumente utilizado em finanças e saude, pois é confiavel para transferir dados sensiveis
    pode ser utilizado em SMTP.
)
- Rest - (
    é um padrao de arquitetura e conjunto de regras que formam o Rest
    todo recurso da sua API deve ter uma URL. (/produto, /usuario...)
    neste padrao é utilizado os verbos HTTP para referenciar as operações (get, post, delete, ...)
    cada interação com a API é independente não guardando dados da interação anterior
).
